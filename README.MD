# TASKFLOW

## Descipción del proyecto

Aplicación interactiva que permite a los usuarios gestionar tareas de manera eficiente y ordernarlas segun el estado de la misma.

Se creo con el objetivo de poner en practica y aplicar conceptos fundamentales de desarrollo Front-End utilizando HTML, JavaScriop y CSS.

## Funcionalidades

- Ingreso de tareas.
- Organizar tareas entre "No realizadas", "En proceso" y "Finalizadas".
- Ingreso de fecha límite para realizar al tarea y cuenta regresiva de días.
- Permite guardar las tareas en el localStorage.
- Visualización de fecha actual y clima según la localización de la IP.

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript ES6+
- API de Open-Meteo
- Bootstrap

## Justificación técnica

- JavaScript modularizado en archivos según funcionalidad para no tener un archivo final muy extenso.
- CSS único para los estilos de la aplicación.
- Uso de localStorage para simulación de mantención de datos.
